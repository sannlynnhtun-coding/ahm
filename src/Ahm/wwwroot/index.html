Ahm — a staff-assisted loyalty workspace for shops

Ahm helps shop owners and authorised staff record purchases, stamps, cashback and rewards in a Google Sheet owned by the shop. This public homepage is available without signing in.

When a user chooses to connect Google, Ahm requests the drive.file permission so the browser can create, open and update only the Google Drive files created with or selected for Ahm. Ahm does not request access to the user's entire Drive.

Google user data is used only to provide Ahm's visible loyalty features. It is not sold, used for advertising or credit decisions, used to train AI/ML models, or used to generate or process intimate imagery.
